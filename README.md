# PHENOMENA

An interactive physics laboratory in the browser. The initial lab, **GRAVITY**, is planned as a deterministic 2D Newtonian N-body simulation; later labs are WAVES and MOTION.

**State:** GRAVITY feature under implementation. Physics, interaction, persistence and visual engine are implemented in a feature branch. CI and browser/deployment validation are separate release gates and must be recorded before claiming a shipped MVP.

## Product contract

- [`PRODUCT.md`](PRODUCT.md): user outcomes, physics model, user interaction, constraints and acceptance criteria.
- [`DESIGN.md`](DESIGN.md): scientific instrument visual style and accessible responsive layouts.
- [`AGENTS.md`](AGENTS.md): local AI development/approval rules adopted from Foundation.
- [`docs/VERIFICATION.md`](docs/VERIFICATION.md): acceptance and delivery checklist.

## Setup

Prerequisite: Node.js **24.20.0** (`.node-version`) and npm. After obtaining the repository:

```bash
npm ci
npm run check
npm run typecheck
npm test
npm run build
npm run dev
```

`package-lock.json` was generated by npm in [GitHub Actions run 38038122384](https://github.com/ShimaBell0619/phenomena-lab/actions/runs/38038122384) and committed as an exact lockfile. The app's normal PR CI uses `npm ci` and validates its scripts/build; this README is not proof that PR CI or browser rendering has passed.
